# 온라인 교회 투어

우리 교회 사진으로 만드는 360도 가상 투어입니다. 전도축제 초대 링크로 쓰도록 만들었습니다.
빌드 과정도 서버도 없습니다. 파일 몇 개를 올리면 끝입니다.

**예시: [예임교회 온라인 투어](https://hhong0326.github.io/church-tour/)** (폰으로 열어보세요)

- 화면을 끌어서 교회 안을 둘러봅니다
- 피아노, 세컨 피아노, 드럼, 베이스, 일렉 기타, 통기타를 직접 연주할 수 있습니다
- 카페에서 음료를 고르면 쿠폰 화면을 받습니다
- 오른쪽 위 초대장에 축제 일시와 장소가 나옵니다

## 우리 교회용으로 만들기

1. 이 저장소를 복사(fork)합니다.
2. `photos/` 에 공간별 사진을 넣습니다.
3. `config.js` 에서 교회 이름, 초대 문구, 공간, 표시 위치를 고칩니다. `index.html` 은 그대로 둡니다.
4. 표시 위치는 주소 끝에 `#edit` 를 붙여 열고 사진을 누르면 나오는 `yaw`, `pitch` 값을 붙여 넣습니다.
5. `index.html` 맨 위의 공유 미리보기(`og:`) 줄을 우리 교회 내용과 주소로 고칩니다. (아래 "공유 미리보기" 참고)
6. 정적 호스팅에 폴더째 올립니다. 가장 쉬운 방법은 GitHub Pages 입니다.
   - 저장소 Settings → Pages → Source 를 `Deploy from a branch`, Branch 를 `main` / `(root)` 로 고르고 저장
   - 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다
   - Cloudflare Pages, Netlify 도 빌드 명령 없이 그대로 올리면 됩니다

내 컴퓨터에서 미리 보려면 폴더에서 `python3 -m http.server` 를 실행하고 `http://localhost:8000` 을 엽니다.
(파일을 더블클릭해서 열면 브라우저 보안 정책 때문에 사진이 안 나옵니다.)

## 사진 찍는 법

- **360도 사진(가로:세로 2:1)** 이 가장 좋습니다. 360 카메라나 폰의 360 촬영 앱으로 공간 가운데에서 눈높이로 찍습니다.
- **폰 파노라마, 일반 사진** 도 됩니다. 이때는 `config.js` 의 해당 공간에 `hfov`, `vfov`(사진이 담은 좌우, 상하 각도)를 적어주면 더 자연스럽습니다.
- 사람 얼굴이 나오지 않게 빈 공간일 때 찍습니다.
- 가로 4096px 정도, 장당 1MB 안팎으로 줄여 올리면 모바일에서 빨리 뜹니다.

## 초대장

`config.js` 의 `invite` 에 제목, 일시와 장소(`lines`), 안내 문구(`note`)를 적습니다. `map` 에 지도 주소(네이버 지도, 카카오맵 등)를 넣으면 초대장 아래에 "지도 보기" 버튼이 생깁니다.

## 표시 종류

| type | 동작 | 필요한 값 |
|---|---|---|
| `go` | 다른 공간으로 이동 | `to` (공간 id) |
| `info` | 안내 글 보기 | `title`, `body` |
| `instrument` | 악기 연주 화면 열기 | `id` (`config.js` 의 `instruments` 이름) |
| `cafe` | 카페 메뉴 열기 | 없음 (`config.js` 의 `cafe` 사용) |

## 악기

`config.js` 의 `instruments` 에서 이름, 종류, 소리, 사진을 정합니다. 우리 교회에 없는 악기는 지우면 됩니다.

| kind | 연주 방식 | sound |
|---|---|---|
| `keys` | 건반 (여러 건반 동시에, 쓸기 가능) | `piano`, `epiano` |
| `drums` | 패드 6개 (킥, 스네어, 하이햇, 오픈 하이햇, 탐, 크래시) | 없음 |
| `strings` | 코드 버튼 + 줄 쓸기 | `acoustic`, `electric`, `bass` |

### 따라 치기

`config.js` 의 `songs` 에 곡을 넣으면 악기 화면에 곡 버튼이 생깁니다. 다음에 칠 것에 불이 켜지고, 누를 때까지 기다려 줍니다.
저작권이 끝난 곡만 넣어주세요.

| 값 | 쓰는 악기 | 적는 법 |
|---|---|---|
| `notes` | 건반 | 멜로디. `C4`(가운데 도)부터 `E5` 까지, 반음은 `F#4` 처럼 |
| `chords` | 기타, 베이스, 드럼 | 코드 진행. `G C D Em Am F` 를 쓸 수 있습니다. `\|` 는 마디 구분, `C-G` 는 한 마디에 두 코드 |
| `drums` | 드럼 (선택) | 칠 순서. `kick snare hat open tom crash`. 없으면 코드마다 킥, 스네어를 치고 끝에 크래시 |

- 기타: 다음 코드 버튼에 불이 켜지고, 누르면 그 코드를 칩니다.
- 베이스: 다음 코드 버튼과 맨 위 줄(근음)에 불이 켜집니다. 둘 중 하나를 누르면 근음이 울립니다.
- 드럼: 다음에 칠 패드에 불이 켜집니다.

```js
{ title: "기뻐하며 경배하세",
  notes: "E4 E4 F4 G4 G4 F4 E4 D4 ...",
  chords: "C G C G | C G C-G C" },
```

### 배경 음악

`config.js` 의 `bgm` 에 곡을 넣으면 "둘러보기 시작"을 누른 뒤 작게 반복됩니다. 오른쪽 위 스피커 버튼으로 끄고 켤 수 있고, 끈 상태는 기억합니다. 악기를 여는 동안에는 소리가 줄어듭니다.
`bgm` 을 지우면 배경 음악 없이 동작합니다.

```js
bgm: {
  volume: 0.35,                 // 0 ~ 1
  songs: [
    { title: "곡 이름", tempo: 100,   // 1분에 4분음표 몇 개
      parts: [
        "E4:0.5 F4:0.5 G4:1 ...",     // 첫 줄은 멜로디 ("음이름:박자", 쉼표는 R:박자)
        "C3:1 G2:1 ...",              // 다음 줄부터 반주 (몇 줄이든 됩니다. 마지막 줄을 베이스로 칩니다)
      ] },
  ],
},
```

예시의 두 곡(참 아름다워라, 기쁘다 구주 오셨네)은 [Open Hymnal Project](https://openhymnal.org/) 의 공개(public domain) 4성부 악보에서 옮겼습니다.

소리는 전부 브라우저에서 합성합니다. 음원 파일이 없어서 저작권 걱정도, 용량 부담도 없습니다.

## 필요한 사진

파일 이름은 `config.js` 의 `image` 값과 같으면 됩니다. 아래는 예시 설정(엘리베이터에서 시작하는 상가 교회) 기준입니다.

| 파일 | 내용 |
|---|---|
| `photos/elevator-1f.jpg`, `elevator-in.jpg` | 1층 엘리베이터 앞(시작점), 엘리베이터 안(층 버튼이 보이게) |
| `photos/3f-hall.jpg`, `4f-hall.jpg`, `4f-lobby.jpg` | 각 층 엘리베이터에서 내린 자리, 교회 입구 |
| `photos/sanctuary.jpg`, `stage.jpg`, `cafe.jpg` | 본당, 무대 앞(악기가 보이게), 카페 (360도 권장) |
| `photos/inst-piano.jpg`, `inst-keys2.jpg`, `inst-drums.jpg`, `inst-bass.jpg`, `inst-eguitar.jpg`, `inst-aguitar.jpg` | 악기 사진. 연주 화면 위에 가로로 길게 나옵니다 (가로 1200px 정도면 충분) |
| `photos/og.jpg` | 링크를 공유했을 때 나오는 미리보기 사진 (가로 1200 x 세로 630px) |

사진이 없는 항목은 임시 배경이 나오거나 사진 자리만 비워집니다.

건물 구조가 다르면 `config.js` 의 `scenes` 를 우리 교회 동선대로 고치면 됩니다. 엘리베이터의 층 버튼은 `go` 표시에 "3층" 같은 라벨을 붙인 것입니다.

## 공유 미리보기

카카오톡이나 인스타그램에 링크를 보냈을 때 나오는 제목과 사진은 `index.html` 맨 위의 `og:` 줄에서 정합니다.
(미리보기는 `config.js` 를 읽지 못해서, 이 부분만은 `index.html` 을 직접 고쳐야 합니다.)
`og:image` 는 배포한 뒤 `https://` 로 시작하는 전체 주소로 적어주세요.
